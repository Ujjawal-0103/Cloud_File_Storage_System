# Cloud File Storage System - Frontend

Frontend built using **Next.js**, **React**, **Tailwind CSS**, and **TypeScript**.

---

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Axios
- React Hook Form
- Zod
- shadcn/ui

---

# Prerequisites

Install

- Node.js
- npm
- Git

Verify

```bash
node -v
npm -v
```

---

# Clone Repository

```bash
git clone <repository-url>
```

Navigate to frontend

```bash
cd frontend
```

---

# Install Dependencies

```bash
npm install
```

---

# Environment Variables

Create

```
.env.local
```

Example

```env
NEXT_PUBLIC_API_URL=http://localhost:3001
```

---

# Run Frontend

Development

```bash
npm run dev
```

Production

```bash
npm run build

npm run start
```

---

# Open Application

```
http://localhost:3000
```
